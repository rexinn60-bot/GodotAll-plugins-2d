GodotAll-plugins-2d

为移动端 Godot 编辑器开发的节点层级调整插件。

解决什么问题

在手机上用 Godot 开发时没有键盘，无法使用 Ctrl + 上/下 之类的快捷键来快速调整节点层级。

本插件在编辑器顶部工具栏添加了上/下箭头按钮，选中节点后点一下即可上移或下移层级，替代桌面端的快捷键操作，无需键盘。

支持版本

Godot 4.x

支持范围

插件操作的是节点层级，因此 2D 和 3D 节点均适用（名字带 2d 只是习惯叫法）。

使用方式

1. 下载仓库中的 addons.zip
2. 解压后，把 addons/ 文件夹放到项目根目录
3. 打开 项目设置 → 插件，启用本插件
4. 启用后，编辑器顶部工具栏会出现上/下箭头图标
5. 选中任意节点，点击箭头即可上移或下移层级

如果图标没有显示，请检查插件是否已启用，以及编辑器版本是否为 4.x。

说明

本插件的代码与调试均在手机上完成（纯手机手搓），所以特别理解手机端没有键盘、操作受限的痛点。桌面端如有异常，欢迎反馈。
